The downloader validates the archive before parsing it. A Git LFS pointer is not
the dataset and will fail that check. JSON is used because the upstream
[download documentation](https://github.com/hetio/hetionet#download-hetionet)
states that JSON and Neo4j retain properties absent from the TSV and matrix
exports, including licensing information.

## Transformation

The preparation script streams the archive and retains four entity types and
four evidence relationship types. The output contains 24,456 nodes and 255,730
evidence edges. The 755 `Compound–treats–Disease` records are retained as a
separate label list. Palliative relationships never enter features.

Each node keeps its original identifier, name, label, URL where supplied and
metadata. IDs are qualified with the type to prevent collisions. Each edge
keeps its endpoints, type, original metadata, available source list and license.
The graph manifest records preprocessing counts and a hash of the serialized
graph in addition to the raw archive hash.

Source identifiers may refer to databases rather than individual papers.
Consolidated relationships can combine multiple sources, so the number of edges
is not a count of independent experiments. ARIADNE displays the available
provenance without manufacturing missing citations or confidence scores.

## Licensing

The upstream Hetionet repository releases its original content under CC0 while
explicitly retaining constituent resources' terms. See the upstream
[license statement](https://github.com/hetio/hetionet#license) and
[source license table](https://github.com/dhimmel/integrate/blob/master/licenses/README.md).

ARIADNE's MIT license covers its original application code and documentation.
It does not override source-data licenses. Available per-node and per-edge
license attributes are preserved. A missing license field is recorded as missing
and is not interpreted as permission for unrestricted commercial reuse.

The repository stores small manifests, model parameters and benchmark results.
Bulk raw and processed graph files are downloaded or regenerated by `make data`
rather than silently relicensed as project source.
