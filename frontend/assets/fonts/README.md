# Bundled typefaces

The landing page and interface use **Manrope**, with **Instrument Serif** for
editorial display text. Webfonts are served locally; page visitors make no font
requests to Google or another third party.

- Manrope, Google Fonts v23 Latin WOFF2: https://fonts.gstatic.com/s/manrope/v23/xn7gYHE41ni1AdIRggexSg.woff2
- Instrument Serif, Google Fonts v5 Latin regular WOFF2: https://fonts.gstatic.com/s/instrumentserif/v5/jizBRFtNs2ka5fXjeivQ4LroWlx-6zUTjg.woff2
- Instrument Serif, Google Fonts v5 Latin italic WOFF2: https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7M.woff2

Original projects: [Manrope](https://github.com/googlefonts/manrope) and
[Instrument Serif](https://github.com/Instrument/instrument-serif).
The unmodified SIL Open Font License files are retained in this directory.
The combined WOFF2 payload is 67,692 bytes. System fallbacks cover glyphs beyond
the bundled Latin subset, and `font-display: swap` keeps text visible during load.
